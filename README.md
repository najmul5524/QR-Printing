# 🖨️ QR Se Print - Cyber Cafe & Print Shop Auto-Print System

গ্রাহক ফোনের ক্যামেরা দিয়ে দোকানের **QR কোড স্ক্যান** করে ফাইল পাঠাবে, পেমেন্ট করবে এবং দোকানের উইন্ডোজ প্রিন্টার থেকে **স্বয়ংক্রিয়ভাবে (Auto-Print)** প্রিন্ট বের হয়ে আসবে — কোনো হোয়াটসঅ্যাপ বা পেনড্রাইভ ছাড়াই!

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)
- 📱 **কোনো অ্যাপ ছাড়া গ্রাহকের জন্য সহজ ব্যবস্থা:** সাধারণ মোবাইল ব্রাউজার দিয়েই ফাইল সিলেক্ট, সাইজ ও কালার নির্ধারণ করা যায়।
- ⚡ **অটোমেটিক প্রিন্ট (Auto-Print):** কাস্টমার পেমেন্ট করা মাত্র বা দোকানদার অনুমোদন দেওয়া মাত্র কোনো ক্লিক ছাড়াই প্রিন্ট বের হবে।
- 💵 **বাংলাদেশ ভিত্তিক পেমেন্ট সিস্টেম:** বিকাশ (bKash), নগদ (Nagad) এবং কাউন্টারে নগদ ক্যাশ পেমেন্ট সমর্থন করে।
- 🔒 **১০০% ফাইল প্রাইভেসি ও অটো-ডিলিট:** প্রিন্ট হওয়া মাত্রই পিসি এবং সার্ভার থেকে ফাইল তাৎক্ষণিক ও পার্মানেন্টলি ডিলিট হয়ে যায়।
- 👁️ **আসল প্রিন্ট প্রিভিউ:** প্রিন্টের আগে প্রতিটি শিট (N-up, সাদাকালো/রঙিন, ৪×৬, NID) ঠিক যেমন প্রিন্ট হবে তেমন দেখা যায় — মোবাইলেও কাজ করে।
- 🪪 **NID / ID কার্ড (আসল মাপ):** সামনে-পেছনের দুটি ছবি A4 পেজে ঠিক **৮৫.৬ × ৫৪ মিমি** মাপে বসে, কাটার দাগ ও ৫০ মিমি স্কেল-রুলার সহ। ছবি ঘোরানো, Crop/Fit বেছে নেওয়া যায়।
- 📲 **QR ফাইল ট্রান্সফার (`/transfer`):** লগইন ছাড়াই মোবাইল ↔ পিসি যেকোনো ফাইল (সব ধরন, ≤৫০ MB, একসাথে অনেক ফাইল)। এক পাশে QR দেখায়, অন্য পাশ স্ক্যান করে — দুই দিক থেকেই আপলোড/ডাউনলোড, রিয়েলটাইম আপডেট, ZIP ডাউনলোড। ১২ ঘণ্টা পর অটো-ডিলিট।
- 📷 **ফটো স্টুডিও:** পাসপোর্ট/ভিসা/স্ট্যাম্প/নিজের সাইজের ছবি A4 বা ৪×৬ পেপারে সারিবদ্ধভাবে আসল মাপে সাজানো (একসাথে ৩ ধরনের সাইজ), ব্রাইটনেস, কনট্রাস্ট, সাদাকালো, জুম/পজিশন ও ব্যাকগ্রাউন্ড রঙ বদল, লাইভ প্রিভিউ।
- 📤 **দোকানে ফাইল পাঠানো:** কাস্টমার যেকোনো ফাইল (≤৫০ MB) দোকানের ড্যাশবোর্ডে পাঠাতে পারে; দোকানদারও লিংক/কিউআর/৮ অক্ষরের কোড দিয়ে কাস্টমারকে ফাইল দিতে পারে (একবার-ডাউনলোড অপশন সহ)। ২৪ ঘণ্টা পর অটো-ডিলিট।
- 🖼️ **৪×৬ পাসপোর্ট ফটো শিট:** কাস্টমার ছবি দিলে স্বয়ংক্রিয়ভাবে ৬ কপির পাসপোর্ট শিট সাজিয়ে প্রিন্টারে পাঠায়।
- 📝 **ইন-বিল্ট রেজুমে মেকার:** কাস্টমার দোকানে বসেই দ্রুত সিভি/বায়োডাটা তৈরি করে প্রিন্ট নিতে পারে।
- 🖨️ **প্রিন্ট স্ট্যান্ডি পোস্টার:** দোকানের কাউন্টারে টানিয়ে রাখার মতো রেডিমেড কিউআর কোড পোস্টার জেনারেটর।

## 🛠️ ১. লোকাল কম্পিউটারে রান করার নিয়ম (Local Run)

### ধাপ ১: ডিপেনডেন্সি ইনস্টল করুন
আপনার টার্মিনালে নিচের কমান্ডটি চালান:
```bash
pip install -r requirements.txt
pip install pywin32 websockets
```

### ধাপ ২: সার্ভার চালু করুন
```bash
python main.py
```
সার্ভারটি `http://localhost:8000` এ চালু হবে।
- **হোমপেজ:** `http://localhost:8000/`
- **দোকানদারের ড্যাশবোর্ড:** `http://localhost:8000/admin`
  - ডেমো মোবাইল: `01700000000`
  - ডেমো পাসওয়ার্ড: `123456`
- **কাস্টমার পেজ:** `http://localhost:8000/p/demo101`

### ধাপ ৩: উইন্ডোজ প্রিন্ট এজেন্ট চালু করুন
1. `agent/start_agent.bat` ফাইলে ডাবল ক্লিক করুন।
2. এজেন্ট স্বয়ংক্রিয়ভাবে সার্ভারের সাথে যুক্ত হবে এবং ড্যাশবোর্ডে **"উইন্ডোজ এজেন্ট সংযুক্ত"** সবুজ ব্যাজ দেখাবে।

## 🌐 ২. Render-এ সম্পূর্ণ ফ্রিতে ডিপ্লয় করার নিয়ম (Render Deployment Guide)

1. এই ফোল্ডারের ফাইলগুলো একটি **GitHub Repository**-তে পুশ করুন।
2. [Render.com](https://render.com)-এ লগইন করে **New +** বাটনে ক্লিক করে **Web Service** সিলেক্ট করুন।
3. আপনার গিটহাব রিপোজিটরিটি কানেক্ট করুন।
4. নিচের সেটিংসগুলো পূরণ করুন:
   - **Name:** `qr-se-print` (বা আপনার পছন্দের নাম)
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **Plan:** `Free`
5. **Create Web Service** বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে আপনার সাইট লাইভ হয়ে যাবে (যেমন: `https://qr-se-print.onrender.com`)।

## 🖥️ ৩. দোকানের পিসির সাথে Render সার্ভার যুক্ত করার নিয়ম

1. দোকানের কম্পিউটারে `agent/` ফোল্ডারটি কপি করুন।
2. আপনার Render সাইটের অ্যাডমিন প্যানেলে (`https://your-app.onrender.com/admin`) লগইন করে আপনার **API Key** কপি করুন।
3. `agent/agent_config.json` ফাইলটি ওপেন করে Render এর URL এবং API Key বসিয়ে সেভ করুন:
```json
{
    "server_url": "https://your-app.onrender.com",
    "api_key": "qsp_আপনার_দোকানের_এপিআই_কি"
}
```
4. এবার `agent/start_agent.bat` চালু করে রাখুন। এখন দূর থেকে বা দোকানে বসে যেকোনো কাস্টমার আপনার কিউআর কোড স্ক্যান করে প্রিন্ট দিলেই দোকানের উইন্ডোজ প্রিন্টার স্বয়ংক্রিয়ভাবে প্রিন্ট করে দেবে!

## 🪪 ৪. NID কার্ড একদম আসল সাইজে প্রিন্টের টিপস

সার্ভার একটি A4 **PDF** বানায় যেখানে কার্ড ৮৫.৬×৫৪ মিমি। প্রিন্টারে PDF ভিউয়ার "Fit to page" করলে মাপ সামান্য ছোট হয়ে যায়। তাই:

1. [SumatraPDF](https://www.sumatrapdfreader.org/) (ফ্রি, Portable) ডাউনলোড করে `SumatraPDF.exe` ফাইলটি `agent/` ফোল্ডারে রাখুন। এজেন্ট নিজে থেকে এটি খুঁজে নিয়ে **কোনো স্কেলিং ছাড়া (noscale)** প্রিন্ট করবে এবং কপি সংখ্যাও ঠিক মানবে।
2. প্রিন্ট বের হলে শিটের নিচের **৫০ মিমি দাগ** স্কেল দিয়ে মেপে দেখুন।
3. নির্দিষ্ট প্রিন্টার চাইলে `agent_config.json`-এ `"printer_name": "আপনার প্রিন্টারের নাম"` দিন।

> এজেন্ট কোড বদলেছে — `.exe` ব্যবহার করলে আবার বিল্ড করুন: `pyinstaller QRSePrint_Agent.spec`

## 📤 ৫. ফাইল ট্রান্সফার কীভাবে কাজ করে

- **কাস্টমার → দোকান:** কাস্টমার পেজে (`/p/<shop_code>`) "ফাইল ট্রান্সফার" ট্যাব → ফাইল বাছাই → পাঠান। দোকানদারের `/admin` ড্যাশবোর্ডের "ফাইল ট্রান্সফার" অংশে সাথে সাথে দেখা যায়।
- **দোকান → কাস্টমার:** ড্যাশবোর্ড থেকে ফাইল আপলোড করলে কিউআর + লিংক (`/t/<কোড>`) পাওয়া যায়।
- নিরাপত্তা: `.exe/.bat/.apk` ইত্যাদি ব্লক, ফাইল সর্বোচ্চ ৫০ MB, প্রতি দোকানে সর্বোচ্চ ৪০টি পেন্ডিং ফাইল, ২৪ ঘণ্টা পর অটো-ডিলিট।

## ⚠️ Render ফ্রি প্ল্যানের সীমাবদ্ধতা
Render ফ্রি প্ল্যানে ডিস্ক **স্থায়ী নয়** — প্রতিবার ডিপ্লয়/রিস্টার্টে SQLite ডাটাবেজ (`data/qrprint.db`) ও আপলোড করা ফাইল মুছে যায় (দোকান অ্যাকাউন্টও নতুন করে খুলতে হয়)। স্থায়ী ডাটার জন্য Render **Persistent Disk** (পেইড) অথবা বাইরের ডাটাবেজ ব্যবহার করুন। `SECRET_KEY` এনভায়রনমেন্ট ভ্যারিয়েবল সেট থাকলে লগইন সেশন রিস্টার্টের পরও বৈধ থাকে (`render.yaml` এ স্বয়ংক্রিয়ভাবে বানানো হয়)।

## 📲 ৬. QR ফাইল ট্রান্সফার (মোবাইল ↔ পিসি)
`https://আপনার-সাইট/transfer` → "নতুন ট্রান্সফার শুরু করুন" → QR আসবে → অন্য ডিভাইসে স্ক্যান করুন। সেশনের কোড (৮ অক্ষর) যার কাছে আছে সে-ই ফাইল দেখতে পায়। সীমা: ফাইলপ্রতি ৫০ MB, সেশনে ৩০টি ফাইল / মোট ৩০০ MB, ১২ ঘণ্টা (`main.py` এর `ROOM_*` ধ্রুবকে বদলানো যায়)। ডাউনলোড সবসময় attachment হিসেবে হয়, তাই আপলোড করা HTML ফাইল সাইটে চলতে পারে না।

## 📷 ৭. ফটো স্টুডিও
- সাইজ প্রিসেট: ৪৫×৫৫, ৩৫×৪৫, ১.৫×২ ইঞ্চি, ২৫×৩০, স্ট্যাম্প ২০×২৫ মিমি + নিজের সাইজ। বাংলাদেশে পাসপোর্টের ছবির সাইজ আবেদনের ধরনভেদে ভিন্ন বলে উৎসগুলোতে মিল নেই, তাই **আবেদনের আগে পাসপোর্ট অফিস থেকে সাইজ নিশ্চিত করুন**।
- ব্যাকগ্রাউন্ড বদল সমান রঙের দেয়াল/পর্দায় সবচেয়ে ভালো কাজ করে (AI কাটআউট নয়); প্রিভিউ দেখে "ব্যাকগ্রাউন্ড ধরার মাত্রা" স্লাইডার ঠিক করুন।
- A4 ফটো শিটের দাম আলাদা: ড্যাশবোর্ড → সেটিংস → "A4 ফটো শিট"। ৪×৬ শিটে দাম = "৪×৬ ফটো শিট"।

## 🔑 ৮. এজেন্ট API Key
`run_agent.bat` চালালেই প্রতিবার API Key চাইবে। কী আর `agent_config.json`-এ সেভ হয় না (পুরনো সেভ করা কী থাকলে প্রথমবার চালালে মুছে ফেলা হয়)।

## ⏰ ৯. Render সচল রাখা (cron-job) ও ব্যান্ডউইথ
- কিপ-অ্যালাইভ লিংক: `https://<আপনার-সাইট>.onrender.com/ping` (উত্তর মাত্র `ok`)। [cron-job.org](https://cron-job.org)-এ প্রতি **১০ মিনিটে** এই লিংকে GET/HEAD সেট করুন (Render ১৫ মিনিট ট্রাফিক না পেলে স্লিপ করে)।
- Render-এ শুধু **আউটবাউন্ড** ট্রাফিক (সার্ভার থেকে বের হওয়া ডাটা, যেমন ডাউনলোড/প্রিভিউ ছবি) ব্যান্ডউইথ হিসেবে গোনা হয়। আপলোড (ইনবাউন্ড) ফ্রি।
